# Praktikum Laravel - C030325006

## Deskripsi

Repository ini merupakan proyek praktikum mata kuliah Pemrograman Web menggunakan Laravel 13. Proyek ini digunakan untuk mempelajari pengembangan aplikasi web berbasis Laravel, mulai dari struktur project, routing, Blade, controller, database, hingga pengelolaan project menggunakan Git dan GitHub.

## Teknologi yang Digunakan

- Laravel 13
- PHP 8.4
- MySQL/MariaDB
- Composer
- Vite
- Git
- GitHub

## Persyaratan

Sebelum menjalankan project, pastikan sudah terpasang:

- PHP
- Composer
- MySQL atau MariaDB
- Node.js dan npm
- Git
